## Prerequisites

- Kubernetes cluster
- Crossplane installed
- Required Functions installed (e.g., `patch-and-transform`)

## Quickstart

0. Change working dir to this directory
```bash
cd crossplane-projects/packages/saas
```

1. Install required namespace:

```bash
kubectl create namespace saas-system
```

2. Install required Crossplane Functions:

```bash
kubectl apply -f ../../_prerequisites/functions/crossplane-contrib-function-patch-and-transform.yaml
```

3. Build and push the package:

```bash
make push
```

4. Apply the Configuration. This will fetch from pushed artifact generated by `make push`.

```bash
kubectl apply -f ../../examples/saas/deploy-vanilla-kubernetes.yaml
```

5. Apply the Workspace XR:

```bash
kubectl apply -f examples/workspace.yaml
```

5. Check the xxx status:

```bash
kubectl get configmap -n saas-system
```

## Clean Up

```bash
# Delete the Workspace
kubectl delete -f examples/workspace.yaml

# Delete the Configuration
kubectl delete -f ../../examples/saas/deploy-vanilla-kubernetes.yaml
```

## Structure

```
.
├── Makefile          # Build, push, and future commands
├── crossplane.yaml   # Composition definition
└── README.md
```

## Notes

* The Composition does **not create resources by itself** — you must instantiate the `SaaSBootstrap` XR.
* Functions and providers must be installed in the cluster beforehand.
* Namespace `saas-system` must exist before applying resources.
