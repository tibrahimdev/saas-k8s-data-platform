## Techdocs
The technical documentation of this project is created using [MkDocs](https://mkdocs.org) and available on [docs/](./docs/) directory.
To serve the documentation locally you can run following command:

```bash
# Run mkdocs on http://localhost:8000
mkdocs serve

# Run mkdocs on custom port
mkdocs serve -a localhost:CUSTOM_PORT
```
